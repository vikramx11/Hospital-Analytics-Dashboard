# Hospital Analytics Dashboard

## Project Overview

This project is developed using Microsoft Power BI to analyze hospital operations and patient-related data.

The dashboard provides insights into patient admissions, hospital revenue, department performance, billing, and doctor activities through interactive visualizations.

## Tools Used

- Microsoft Power BI
- DAX
- Data Visualization

## Dashboard Pages

### 1. Overview
- Total Patients
- Total Admissions
- Total Revenue
- Average Length of Stay
- Admissions by Department
- Admissions by Type
- Revenue by Department
- Monthly Admissions Trend

### 2. Patients
Provides insights into patient-related information and admission details.

### 3. Billing
Displays hospital revenue and billing-related analysis.

### 4. Doctors & Department
Provides department-wise and doctor-wise performance analysis.

## Features

- Interactive dashboard navigation
- KPI cards
- Department filters
- Date range filters
- Multiple chart visualizations
- Patient and admission analysis
- Revenue analysis

## Project File

File: Hospital_analytics.pbix

The project can be opened using Microsoft Power BI Desktop.

## Objective

The objective of this project is to understand hospital operational data and convert it into meaningful insights using data visualization.
